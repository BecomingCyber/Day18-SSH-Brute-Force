# Security Policy

## Purpose

This repository contains cybersecurity training labs designed for defensive security education, SOC analyst practice, and incident response skill development.

All activities are performed in controlled laboratory environments.

---

## Scope

This project demonstrates:

- Security monitoring
- Log analysis
- Incident response workflows
- SIEM investigations
- Evidence validation automation

---

## Responsible Use

The techniques demonstrated in this repository should only be used on systems where authorization has been provided.

Do not use these techniques against systems you do not own or have permission to test.

---

## Reporting Security Issues

If you identify a security issue within this repository, please document:

- Description of the issue
- Steps to reproduce
- Potential impact
- Recommended remediation

---

## Educational Disclaimer

This project exists for learning, portfolio development, and defensive cybersecurity training purposes.
